# Le Prestige - Website Project

โปรเจกต์เว็บไซต์ร้านอาหาร Fine Dining 5 หน้าสมบูรณ์ (Single Page Application)

## รายชื่อไฟล์ใน Zip:
- `index.html` : ไฟล์หน้าเว็บหลักที่รวมระบบทั้ง 5 หน้า (หน้าแรก, เกี่ยวกับเรา, เมนู, สำรองโต๊ะ, ติดต่อเรา)
- `README.txt` : คำอธิบายและวิธีใช้งาน

## วิธีเปิดใช้งาน:
1. แตกไฟล์ (Unzip) โฟลเดอร์
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ เช่น Chrome, Edge, หรือ Safari ได้ทันทีโดยไม่ต้องติดตั้ง Server
